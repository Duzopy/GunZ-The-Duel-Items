<hr>
4) We start by Enabling Wireframe mode > Unlinking all vertex > Start linking vertex one by one. <br>
A TIP - All unlinked vertex select them to in BLUE color. <br>

[video 4](https://github.com/Duzopy/GunZ-The-Duel-Items/raw/refs/heads/main/3dsmax/4.mp4)

<hr>
5) Linking Vertex to the nodes (bones), and when linking vertex to the nodes make sure they are in GREEN Color only otherwise IT WON'T WORK! <br>
A TIP :- When linking a vertex to the node(bone) make sure to click on Lock Assigments and after that click Type In-Weights to see to which bone it was linked and what value it has! <br>

[video 5](https://github.com/Duzopy/GunZ-The-Duel-Items/raw/refs/heads/main/3dsmax/5.mp4)


<hr>
6) After linking all your vertex to the nodes(bones) you need to start editing the values of the In-Weights of the vertex and the bone it was linked to, knowing a vertex can be linked to multiple BONES!- This can be done while linking the vertex one by one as well(Suggested way)

Q :- How can I know the right values I need for In-Weights for each vertex and each bone? <br>
A :- You can't know the right value unless you try messing around with it, I suggest you checking old .max files of maiet original work which can be opened only in 3ds max 2010 version and see the values they put for their work and try to do the same and mess with them till you get the best results for your object/mesh because each object has It's own Values.


![video6](https://github.com/Duzopy/GunZ-The-Duel-Items/blob/main/3dsmax/6.gif)



<hr>
7) Continue linking vertexes to the nodes and editing the values till you have a good results that fits your needs, for example this how it should look once you are done. (The preview doesn't have 100% result as it was done in learning stages and test stages.) <br>

![video7](https://github.com/Duzopy/GunZ-The-Duel-Items/blob/main/3dsmax/7.gif)



<hr>

8)Once you're done, you change the name of your mesh/object to what fits into GunZ, for example we are rigging a chest then we name it for example --- "eq_chest_fgunz" ---- and after that we export the file as .elu. <br>

[video 8](https://github.com/Duzopy/GunZ-The-Duel-Items/raw/refs/heads/main/3dsmax/8.mp4)
